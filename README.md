One image summing up 22 November 2026 world news — make.fun bounty entry.

`main.py` renders `entry.png` (1024×1024, deterministic): a dense newspaper broadsheet of Sunday 22 November 2026 — Iran strikes Bahrain, COP31 collapses, drones hit Khartoum, BepiColombo orbits Mercury, and 16 more dated stories.

Run it:

```sh
python3 main.py
```

It writes `entry.png` to `/output/entry.png` directly (no temp file), chmod 0644, and prints the sha256 after reading it back.
